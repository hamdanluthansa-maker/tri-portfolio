## 🎨 Fitur Utama

- **Ultra-Modern Dark Obsidian Theme**: Estetika modern berpadu aksen *Cyber Neon Lime (`#B8FF36`)* & *Dark Emerald*.
- **Interactive Cyberpunk Background Canvas**: Animasi heksagon matriks dan partikel cahaya melayang yang responsif dan hemat daya.
- **Editorial 3-Column Hero Section**: Komposisi layout poster editorial dengan foto cutout transparan resolusi tinggi dan ambient glow pendar neon.
- **453+ Arsip Karya Desain Grafis**: Terkategori rapi (Logo & Brand, Packaging, Layout & Cetak, Ilustrasi Digital, Social Media) dengan thumbnail WebP terkompresi super ringan.
- **Showcase Proyek Vibe Coding**: Menampilkan 6 proyek aplikasi nyata (POSCloud, Rhythm Game, Kinetic Video Synthesizer, Slingshot 3D Game, dll).
- **Mobile First & Fully Responsive**: Navigasi swipeable, galeri 2-kolom khas mobile app (Instagram/Behance), dan touch target optimal di smartphone Android & iOS.
- **Serverless & Edge Ready**: Dikonfigurasi dengan `vercel.json` dan serverless functions di `api/data.js` untuk kecepatan akses global sub-30ms.

## 🚀 Panduan Menjalankan Secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/hamdanluthansa-maker/tri-portfolio.git
   cd tri-portfolio
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server:**
   ```bash
   node server.js
   ```

4. **Buka di browser:**
   - Komputer / Laptop: `http://localhost:3300`
   - Smartphone (Wi-Fi sama): `http://<IP-Lokal-Komputer>:3300`
